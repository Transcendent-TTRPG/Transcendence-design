# Characteristics

Characteristics represent fundamental aptitudes before they translate into concrete actions.
All characteristics start at 0 during character creation. Final value comes from Species bonuses + Synapsis.

## Groups

### Physical

| Abbreviation | Name     | Description |
|---|---|---|
| STR | Strength  | Physical power, force application, grappling, striking |
| AGI | Agility   | Coordination, reaction speed, bodily precision, dodging |
| TEN | Tenacity  | Endurance, pain resistance, recovery, sustained effort |

### Mental

| Abbreviation | Name     | Description |
|---|---|---|
| INT | Intellect | Reasoning, memory, academic knowledge, structured problem-solving |
| CUN | Cunning   | Improvisation, deception, reading intentions, adaptability |
| WIS | Wisdom    | Perception, intuition, judgment, interpreting nuance |

### Social

| Abbreviation | Name     | Description |
|---|---|---|
| CMP | Composure | Self-control, emotional stability, resistance to manipulation |
| AUR | Aura      | Passive involuntary impression projected onto others |
| PRE | Presence  | Active intentional projection; imposing, persuading, inspiring |

## Derived Attributes

| Attribute   | Formula                            | Depends on |
|---|---|---|
| Preparation | (AGI + CUN + CMP) / 3 (round up)  | Agility, Cunning, Composure |
| Resilience  | (TEN + WIS + CMP) / 3 (round up)  | Tenacity, Wisdom, Composure |

Derived attributes must be recalculated whenever a component characteristic changes permanently.

## Synapsis Rule

Each time a specialization reaches a new rank, the character gains +1 to the characteristic associated with that specialization.

**Final Characteristic = Species Bonus + sum of ranks from all associated specializations**
