# Adaptabilidad / Adaptability — #107

Creator-approved authored rule; empirical balance and simulator support pending.
See [the ADR](../adr/panin-adaptability-transfer.md) and `data/system/techniques.yaml`, ID 107.

An innate Panin Active Utility uses a trained source specialization to support
a different target with the same associated characteristic and a concrete
transferable principle. The target S.R. competency contribution is
`max(target_level + target_rank, source_rank)`; all values are actual current
training. Keep the original die, target characteristic and other modifiers.
Only one adaptation applies per roll, without stacking or chaining support.

Maintain 1 pair at NR 1–4, 2 at NR 5–8 and 3 at NR 9+. Each own-activation use
adds/replaces one pair for 3/1 under pressure, without an activation roll or
changing the other pairs. Ordinary unpressured exploration inherits general
Attrition rules. A pair remains until replaced; no rest expiry, upkeep or
per-roll payment. Source rank improvements update support without reactivation.

No lost or granted competencies, unknown knowledge, Techniques, prerequisite
access, borrowed Synapsis, affinity change, weapon competency or Resistance
transfer. Real target practice can progress under normal rules using its own
level/rank; selection grants none and source progress is not duplicated.
Actual learning remains after changing the selected pair.

Mechanical selection may represent a spontaneous association rather than a
consciously planned or named ability. It is not an always-on bonus. In Chei,
initial spontaneous access is approved using accessible experience only,
without a predefined pair, recovery event or first-use scene.

Example: source level 5/rank 3 supports target level 0/rank 0 with 3; target
level 1/rank 1 still uses 3; target level 3/rank 2 instead uses its own 5.
Actual source and target training are never added together.
