# Naghii — Technique Seeds

**Status:** In progress
**Species:** Naghii
**Primary reference:** `docs/canon/species/naghii.md`, `docs/system/technique-origins.md`
**System references:** `docs/system/techniques.md`, `docs/system/competencies.md`, `docs/system/specializations.md`, `docs/system/weapon-technique-profiles.md`

## Purpose

This document does not list finished Techniques.

It also should not list proto-Techniques that only need numbers. Its purpose is earlier than that: to define the Naghii perspectives that can generate Techniques later.

A Technique seed is a conceptual root. It says:

- what kind of problem the Naghii learned to solve
- what worldview made that solution distinct
- what kinds of weapons, bodies, competencies, or situations can express it
- what should remain visible when the final Technique is written

The final Technique may use a spear, shield, dagger, thrown weapon, tail, fang, venom spit, social pressure, astronomy, or archive practice. Species-origin does not mean natural-weapon-only. It means the method exists because this species, with this history and culture, developed that way of solving a problem.

## Technique Lessons From The Existing Examples

The existing spear Techniques in `docs/system/techniques.md` are useful because they show the target quality of a finished Technique:

- `Cerrar la Línea` is not "spear attack with a bonus"; it is a doctrine of making entry unsafe.
- `Recuperar la Distancia` is not "attack and move"; it is a doctrine of restoring the weapon's proper geometry.
- `Clavar el Paso` is not "move then attack"; it is a doctrine of compressing approach and strike into one committed action.

Those are strong because each one begins with a tactical idea, then becomes a rule.

This document should stay one layer above that. A Naghii seed should be able to generate Techniques like those without already being those Techniques.

Example:

**Bad seed:** "Tail Holds the Line: stop one enemy from moving past you."

This is already almost a Technique.

**Better seed:** "Threshold Denial: Naghii combat treats crossing into protected space as the vulnerable moment. Techniques from this seed make entry, passage, access, or initiation costly."

From that one seed, later Techniques could be written for spear, shield, tail, dagger, intimidation, archive gates, or formation defense.

## Seed Format

Each seed uses:

| Field | Purpose |
| --- | --- |
| `concept` | The abstract Naghii principle |
| `world_root` | Why this principle exists in Naghii society |
| `technique_space` | What kinds of Techniques this can generate |
| `possible_expressions` | Weapons, natural forms, competencies, or scene types that can express it |
| `transmission_logic` | How the principle is taught or restricted |
| `authoring_pressure` | What must remain true when writing a finished Technique |
| `avoid` | What would flatten the seed into generic mechanics |

## Naghii Seed Principles

### 1. Threshold Denial

| Field | Value |
| --- | --- |
| `concept` | A boundary is most controllable at the instant someone commits to crossing it. |
| `world_root` | Naghii civilization is built around guarded archive layers, initiation gates, ziggurat thresholds, restricted chambers, and the fear that some knowledge must not be entered casually. Their combat logic naturally treats entry as a sacred and tactical vulnerability. |
| `technique_space` | Techniques that punish entry, deny passage, stop conversion into close pressure, interrupt someone crossing a line, or make access require commitment. |
| `possible_expressions` | Spear, shield, tail, flexible weapons, polearms, daggers at doorways, intimidation, formation defense, archive-warden protocols. |
| `transmission_logic` | Common as a martial principle among guards; ritualized in priestly gatekeeping; deeper versions tied to initiation law. |
| `authoring_pressure` | A finished Technique should care about the enemy's commitment to crossing, entering, approaching, or forcing access. |
| `avoid` | Do not reduce this to generic reaction attacks or permanent zone control. The vulnerable moment is the crossing itself. |

`Cerrar la Línea` could plausibly be a Naghii-origin Technique from this seed if authored through spear practice. It does not need a tail or fang to be Naghii; the Naghii part is the worldview: entry is where authority answers you.

### 2. Preserved Distance

| Field | Value |
| --- | --- |
| `concept` | Proper distance is not empty space; it is a maintained condition of safety, interpretation, and authority. |
| `world_root` | Naghii priests, guards, and interpreters survive by not allowing dangerous things too close too quickly: unknown texts, ruin mechanisms, Abzu signals, political challengers, armed enemies. Their methods favor measured spacing over impulsive contact. |
| `technique_space` | Techniques that restore ideal range, prevent compression, step away without yielding control, hold an opponent at the readable distance, or create time to interpret before contact. |
| `possible_expressions` | Spear, staff, shield, tail, thrown weapons, venom spit, Perception, Evasion, Astronomy, social command. |
| `transmission_logic` | Taught first as caution and posture; weapon schools express it as range discipline; archive schools express it as interpretive delay. |
| `authoring_pressure` | A finished Technique should define what distance is being preserved and why that distance matters tactically. |
| `avoid` | Do not make this simple kiting or free disengagement. It should preserve a meaningful relation, not merely move away. |

`Recuperar la Distancia` fits this seed if it is framed as Naghii range discipline: the point, the body, and the decision all return to the distance where the user can read and answer.

### 3. Committed Compression

| Field | Value |
| --- | --- |
| `concept` | Sometimes the safest answer is to collapse the interval before uncertainty multiplies. |
| `world_root` | Although Naghii culture is careful, it is not passive. Archive enforcers, ruin scouts, and venom-bearing Kha traditions all recognize moments where delay gives danger more time to unfold. In those moments, the answer is a precise, costly commitment. |
| `technique_space` | Techniques that combine approach with action, close a gap before the opponent stabilizes, force contact before a threat fully develops, or turn hesitation into forward authority. |
| `possible_expressions` | Spear, fang, dagger, shield rush, tail wrap, venom delivery, Charge profile, Shadow Pressure profile, Intimidation. |
| `transmission_logic` | Less broadly taught than distance preservation; associated with Kha enforcement, breach response, and dangerous fieldwork. |
| `authoring_pressure` | A finished Technique should leave the user meaningfully committed. The compression is powerful because it costs safety. |
| `avoid` | Do not make this a free movement package. The user chooses commitment before certainty is complete. |

`Clavar el Paso` could come from this seed as a spear expression. The Naghii origin would not be "snakes use spears"; it would be "when the omen becomes action, hesitation ends."

### 4. Coiled Readiness

| Field | Value |
| --- | --- |
| `concept` | Stillness is stored action, not inactivity. |
| `world_root` | Naghii eyes, posture, and ritual conduct emphasize withholding visible intent. In combat and social pressure, they cultivate the ability to appear settled while preparing a precise answer. |
| `technique_space` | Techniques that trigger from waiting, punish overextension, preserve action until a clearer signal appears, or convert stillness into sudden movement. |
| `possible_expressions` | Spear guard, dagger counter, tail restraint, shield interception, Evasion, Poise, Intimidation, Perception. |
| `transmission_logic` | Present in both temple-guard training and priestly conduct; social versions may be taught before martial versions. |
| `authoring_pressure` | A finished Technique should require the user to hold a line, posture, silence, or threat before releasing it. |
| `avoid` | Do not make this passive bonuses for "being calm." It is readiness under a specific pressure. |

This seed is useful for reactive Techniques, but also for social Techniques where the Naghii forces someone else to act first.

### 5. Layered Sensing

| Field | Value |
| --- | --- |
| `concept` | The visible world is only one layer of evidence. Heat, scent, pressure, vibration, pattern, and absence also speak. |
| `world_root` | Naghii biology gives them sensory channels other species often lack, and their archive culture trains them to treat partial signs as meaningful without making them absolute. |
| `technique_space` | Techniques that answer hidden movement, track through degraded evidence, read a target before visual confirmation, or create tactical advantage from non-visual signs. |
| `possible_expressions` | Perception, Tracking, Evasion, ranged weapons, thrown weapons, spear timing, ruin scouting, pursuit scenes. |
| `transmission_logic` | Biological in origin, but teachable as a discipline of attention. Outsiders learn analogues through dust reading, sound, heat tools, scent training, or battlefield pattern work. |
| `authoring_pressure` | A finished Technique should name the evidence being read. The user is not guessing; the world left a trace. |
| `avoid` | Do not turn this into omniscience, danger sense, or automatic detection of hidden things. |

This seed should produce both combat and exploration Techniques. It is one of the strongest bridges between Naghii body and non-Naghii learnability.

### 6. Absence As Evidence

| Field | Value |
| --- | --- |
| `concept` | What is missing can be as important as what remains. |
| `world_root` | The Naghii archive is built from ruined, partial, mistranslated, and incomplete records. Their best interpreters learn not to fill absence too quickly. Missing marks, broken sequences, silent witnesses, and omitted ritual steps become evidence. |
| `technique_space` | Techniques for detecting false trails, resisting bad conclusions, identifying tampering, reading incomplete ruins, or preserving uncertainty until a better action is available. |
| `possible_expressions` | Cryptology, Archaeology, Perception, Theology, Investigation-like play, social interrogation, trap reading. |
| `transmission_logic` | Initiate-level archive discipline; often restricted because it undermines overconfident doctrine. |
| `authoring_pressure` | A finished Technique should not reveal the full truth. It should prevent a wrong commitment or expose the shape of what is missing. |
| `avoid` | Do not make this generic deduction or "the GM gives the answer." It should protect against false certainty. |

This is a core Naghii knowledge seed. It can make non-combat Techniques feel as sharp as weapon Techniques.

### 7. Venom As Commitment

| Field | Value |
| --- | --- |
| `concept` | Venom is not just damage; it is a consequence attached to contact, breach, or exposure. |
| `world_root` | Kha-Naghii hold venom internally and deliver it through contact. Saa-Naghii project venom outward as transmission. Both variants frame venom as dangerous knowledge made bodily: once introduced, it changes the terms of the exchange. |
| `technique_space` | Techniques that make contact costly, mark a target, punish withdrawal, force resistance decisions, blind or impair at short range, or create pressure through the threat of later degradation. |
| `possible_expressions` | Fang, venom spit, poisoned blades, needles, alchemical projectors, daggers, thrown darts, grappling, intimidation. |
| `transmission_logic` | Politically and ritually controlled; Kha and Saa traditions disagree about legitimate use. Outsider versions exist through tools rather than biology. |
| `authoring_pressure` | A finished Technique should care about delivery, exposure, and consequence. The venom changes the next decision, not just the damage line. |
| `avoid` | Do not write "poison attack" as a flat damage rider. Also do not make Poison Resistance the sole Technique root. |

This seed can generate Kha close-contact Techniques, Saa projected Techniques, and non-Naghii weapon Techniques that inherit Naghii venom doctrine through training.

### 8. Holding Dangerous Knowledge

| Field | Value |
| --- | --- |
| `concept` | Some things must be held without being released, shared, believed, or acted on too soon. |
| `world_root` | The Naghii archive exists because knowledge is dangerous. Kha authority, initiation layers, and restricted translation all teach that containment can be a sacred duty. |
| `technique_space` | Techniques that preserve composure under mental pressure, delay action, resist manipulation, keep a secret under interrogation, prevent panic transmission, or hold a dangerous condition from spreading. |
| `possible_expressions` | Focus, Containment, Meditation, Poise, Theology, Leadership-adjacent command, Resistance hybrids. |
| `transmission_logic` | Priestly and Kha-controlled; deeper forms are taught only after initiation tests. |
| `authoring_pressure` | A finished Technique should buy time, preserve agency, or prevent premature release. It should not grant perfect immunity. |
| `avoid` | Do not make this pure mental resistance. The agency comes from discipline, doctrine, posture, or ritual method. |

This seed is the inward counterpart to Threshold Denial: instead of stopping someone else from entering, the user prevents something inside from escaping or taking over.

### 9. Projection Of Interpretation

| Field | Value |
| --- | --- |
| `concept` | To project is to make a reading matter at distance. |
| `world_root` | Saa-Naghii authority is interpretive: they read signs and require others to act on them. Their venom projection echoes the same cultural logic: perception becomes outward pressure. |
| `technique_space` | Techniques that mark, interrupt, warn, blind, signal, designate a target, force a distant response, or make an interpretation actionable before direct contact. |
| `possible_expressions` | Venom spit, thrown weapons, ranged weapons, voice, command, Astronomy, Perception, Leadership-like coordination, battlefield marking. |
| `transmission_logic` | Saa priestly and scout traditions; often disputed by Kha authorities when interpretation becomes command. |
| `authoring_pressure` | A finished Technique should connect reading to projection. The user sees something and sends consequence outward. |
| `avoid` | Do not make this generic ranged offense. The projection should carry information, pressure, or designation. |

This seed lets Saa identity generate more than venom-spit attacks. It can also support ranged, social, and support/control Techniques.

### 10. Ritualized Access

| Field | Value |
| --- | --- |
| `concept` | Access is not only physical; it is procedural, social, and spiritual. |
| `world_root` | Naghii society is layered by initiation. Doors, records, truths, weapons, and doctrines are approached through procedure. A person who does not know the proper sequence is not merely ignorant; they are dangerous. |
| `technique_space` | Techniques that test approach, interrupt improper procedure, create advantage when the user follows a known sequence, exploit an enemy skipping steps, or turn ritual order into tactical order. |
| `possible_expressions` | Shield, spear, social pressure, Theology, Cryptology, Architecture, formation tactics, dueling etiquette, archive defense. |
| `transmission_logic` | Strongly tied to institutions; outsiders can learn it through service, apprenticeship, or theft of procedure. |
| `authoring_pressure` | A finished Technique should care about sequence: before/after, permitted/forbidden, prepared/unprepared. |
| `avoid` | Do not make this abstract bureaucracy flavor. The procedure must create a real tactical or scene effect. |

This seed is good for Techniques that are neither purely martial nor purely scholarly. It turns Naghii culture into timing logic.

### 11. Controlled Misreading

| Field | Value |
| --- | --- |
| `concept` | If others are reading you, decide what evidence they receive. |
| `world_root` | Naghii politics depends on partial knowledge, guarded interpretation, and still presentation. Since everyone knows records can mislead, skilled Naghii also learn to manage the signs they give off. |
| `technique_space` | Techniques that bait a wrong entry, hide commitment, present false vulnerability, manipulate social reads, or make an opponent choose the wrong timing window. |
| `possible_expressions` | Deception, Poise, Intimidation, Evasion, dagger, spear, tail, shield, social conflict. |
| `transmission_logic` | Informally widespread in politics; formalized in some guard and priestly schools; morally suspect in conservative archives. |
| `authoring_pressure` | A finished Technique should produce a wrong read with a bounded consequence. |
| `avoid` | Do not make this generic stealth or lying. It is about feeding a specific false interpretation. |

This seed can produce clever martial Techniques without making the Naghii into simple assassins or tricksters.

### 12. The Archive Must Continue

| Field | Value |
| --- | --- |
| `concept` | Survival matters because the record must outlive the moment. |
| `world_root` | Naghii civilization treats preservation as sacred. Scouts, guards, priests, and scribes are trained to return with the record, protect the witness, preserve the route, and keep the chain of interpretation alive. |
| `technique_space` | Techniques that protect a carrier, preserve evidence, escape with knowledge, stabilize an ally long enough to report, defend a route of retreat, or maintain function under pursuit. |
| `possible_expressions` | Shield, Evasion, Survival, Medicine, March, Leadership-like coordination, Tracking, Architecture, defensive weapons. |
| `transmission_logic` | Common across archive service; specific expressions vary by role. |
| `authoring_pressure` | A finished Technique should define what must be preserved: person, route, object, testimony, map, sample, or time. |
| `avoid` | Do not make this generic defense or healing. Preservation must have an object. |

This seed gives the Naghii a practical survival doctrine beyond mysticism: they are careful because something has to make it back.

## Converting A Seed Into A Technique

When writing a finished Technique from one of these seeds, use this order:

1. Choose the seed principle.
2. Choose the expression: weapon, natural form, specialization, social practice, exploration practice, or hybrid.
3. Define the playable situation.
4. Define the primary system surface.
5. Add only one secondary surface if the fiction truly asks for it.
6. Set the cost from timing and strain.
7. Write restrictions that protect the seed's identity.

The test is:

> Could this Technique exist without the Naghii?

If yes, the origin is too thin.

> Could someone learn it from the Naghii and perform it with a different body or weapon?

If no, the origin has become too species-locked.

The target is the middle: a Technique that carries Naghii thought into action.

## Appendix — Competency Expression Map

This appendix is not a list of species bonuses or a list of everything a Naghii could learn to use.

It is an authoring map for Naghii-origin Technique traditions: when a Naghii Technique is being designed, these are the competency surfaces the species has actually developed into recognizable methods.

The question is not:

> Could a Naghii use this?

The question is:

> Would the Naghii have built a Technique tradition around this?

A Naghii can wear heavy armor or carry a heavy shield as an individual. That does not mean heavy armor or heavy shield are Naghii technique foundations. Naghii-origin Techniques should preserve their agile, controlled, body-aware identity: lightness, precision, flexible contact, sensory reading, and guarded distance.

A surface can be:

- **core** — a natural Naghii technique foundation
- **supporting** — useful as an appendix to a core seed, but not usually the main tradition
- **excluded** — possible for an individual, but not a Naghii-origin technique foundation

This should help prevent two opposite mistakes:

- making Naghii Techniques only about tail, fang, and venom
- making every generic Technique "Naghii" just because a Naghii could learn it

### Naghii Arsenal For Technique Authoring

Naghii-origin Techniques can be expressed through natural weapons, manufactured weapons, social pressure, or specialized knowledge. The arsenal below defines the most important combat surfaces before choosing a seed.

#### Natural weapons

| Natural weapon | Fit | Profiles | Technique emphasis |
| --- | --- | --- | --- |
| `Tail / Cola` | Core | `Interception`, `Line Control`, `Torsion`, `Interruption` | Off-line contact, restraint, threshold disruption, balance control, and curved-path denial. |
| `Bite / Mordisco` | Kha core | `Perforation`, `Corrosion`, `Shadow Pressure`, `Precision` | Fang delivery, close commitment, venom consequence, exact contact, and punishment once the target enters the guarded interval. |
| `Fluid Projection / Fluidos Proyectados` | Saa core | `Precision`, `Volley`, `Ricochet`, `Corrosion` | Exact venom projection, marking, blinding, weakening, and turning a reading into distant consequence. |

`Rend` and `Volley` are possible by anatomy but should be used carefully. Kha fangs can tear, and Saa projection can repeat, but Naghii-origin Techniques should usually foreground consequence, interpretation, distance, access, or controlled delivery rather than raw mauling or volume fire.

#### Manufactured weapons

| Weapon competency | Fit | Profiles | Technique emphasis |
| --- | --- | --- | --- |
| `Spear` | Core | `Perforation`, `Ward`, `Charge`, `Skirmish` | Archive thresholds, measured distance, point-first denial, ritual guard lines, and precise commitment. |
| `Flexible Weapons` | Core | `Torsion`, `Unpredictability`, `Skirmish`, `Interruption` | Tail analogues, coiling, wrapping, angle theft, false line, and interruption through curved contact. |
| `Ranged Weapons` | Core | `Precision`, `Ricochet`, `Volley`, `Corrosion` | Saa-influenced projection, exact venom delivery, target designation, and weakening at distance. This is the manufactured mirror of `Fluidos Proyectados`. |
| `Thrown Weapons` | Supporting | `Precision`, `Ricochet`, `Volley`, `Interruption` | Darts, needles, markers, ruin geometry, warning throws, and quick projection of a reading. Useful, but secondary to the Saa/ranged projection core. |
| `Daggers` | Supporting | `Unpredictability`, `Shadow Pressure`, `Lethality`, `Deflection` | Restricted chambers, venom tools, close enforcement, concealed commitment, and emergency correction when distance collapses. |
| `Shield` | Supporting | `Interception`, `Interruption`, `Line Control`, `Bastion` | Mobile archive-warden protection, doorway denial, witness protection, and procedural access control. `Bastion` should remain rare and light-framed. |
| `Long Blades` | Peripheral | `Flow`, `Rend`, `Deflection`, `Lethality` | Ritual dueling, elegant guard service, and controlled edge work. Useful, but not the central Naghii combat language. |
| `Short Blades` | Peripheral | `Shadow Pressure`, `Corrosion`, `Skirmish`, `Lethality` | Venom-bearing sidearms and narrow interior fighting. Should not replace dagger or spear identity by default. |
| `Axes` | Excluded | `Line Control`, `Rend`, `Sunder`, `Unstoppable` | Possible as tools or regional adaptations, but not a broad species-origin technique foundation. |
| `Maces` | Excluded | `Bastion`, `Impact`, `Sunder`, `Unstoppable` | Too mass-forward and blunt-shock centered for the main Naghii tradition. Individual exceptions can exist outside species-origin design. |

For the Naghii Novice pass, the three core attack surfaces are:

| Core attack surface | Natural / cultural mirror | Shared logic |
| --- | --- | --- |
| `Spear` | `Mordisco / Bite` and fang-first Kha enforcement | Point-first entry, threshold denial, precise commitment, and making approach dangerous. |
| `Flexible Weapons` | `Cola / Tail` | Curved contact, coiling, restraint, interruption, and off-line control without heavy mass. |
| `Ranged Weapons` | `Fluidos Proyectados / Venom Projection` | Exact projection, venom delivery, target marking, weakening contact, and interpretation made consequential at distance. |

### Weapon Technique Profiles

The current weapon layer uses shared Weapon Technique Profiles rather than one tree per weapon. Naghii-origin Techniques can attach to any weapon if the seed supports it, but these profiles have especially clear Naghii expressions.

| Profile | Fit | Naghii focus |
| --- | --- | --- |
| `Perforation` | Core | Threshold denial, preserved distance, committed compression. Excellent for spears, fangs, needles, and any point-first method that makes entry dangerous. |
| `Corrosion` | Core | Venom residue, degrading contact, and effects that make the next decision worse after exposure. Strongest for Kha fang delivery and Saa projection. |
| `Line Control` | Core | Doors, corridors, ziggurat steps, ritual boundaries, guarded chambers, and forced movement through narrow decision points. |
| `Torsion` | Core | Tail, flexible weapons, coiling, wrapping, off-line contact, and control through curved paths rather than straight force. |
| `Precision` | Core | Saa projection, careful target reading, exact venom delivery, and striking the one point that changes the next decision. |
| `Skirmish` | Core | Measured repositioning, light footwork, controlled withdrawal, and preserved distance without abandoning pressure. |
| `Shadow Pressure` | Supporting | Close contact, concealed commitment, fang/dagger work, controlled misreading, and punishing hesitation. Useful, but should not turn Naghii into generic assassins. |
| `Interception` | Supporting | Guarding archive access and answering breach moments through agile occupation of the line, not heavy shield absorption. |
| `Ricochet` | Supporting | Ruin geometry, angled throws, indirect lines, and reading surfaces as part of the battlefield. |
| `Ward` | Supporting | Ritualized access, warning boundaries, and controlled approach when expressed through light or procedural denial. |
| `Flow` | Supporting | Can work for elegant blade traditions when the emphasis is coiled readiness, smooth redirection, or controlled misreading. |
| `Charge` | Supporting | Kha enforcement and committed compression only when precise and costly. It should not become brute rush identity. |
| `Bastion` | Excluded | Too static and heavy as a foundation. Individual Naghii may learn it elsewhere, but it is not a Naghii-origin tradition. |
| `Impact` | Excluded | Blunt shock is not the species' central combat language. Tail impact may exist as a move, but not as a broad technique foundation. |
| `Rend` | Excluded | Fangs and blades can tear, but Naghii technique identity is more about contact consequence, venom, line, and precision than raw tearing. |
| `Volley` | Excluded | Massed projection is less Naghii than exact projection. This belongs elsewhere unless a future doctrine specifically develops it. |

### Armor and Shield Expressions

Naghii armor expression should preserve their identity: careful motion, protected access, and survival of the record. It should not erase their fluidity by default.

| Surface | Fit | Naghii focus |
| --- | --- | --- |
| `Light Armor` | Core | Scout movement, ruin traversal, evasion, sensory reading, and Techniques that preserve mobility while protecting key zones. |
| `Medium Armor` | Supporting | Archive guards and temple wardens may use balanced protection, but Techniques should still preserve body control and precise movement. |
| `Heavy Armor` | Excluded | Not a Naghii-origin foundation. It compromises the light, articulated body use that makes Naghii methods distinct. |
| `Light Shield` | Supporting | Mobile interception, ritual dueling, quick line denial, and protecting a hand or record-bearing side without locking movement. |
| `Medium Shield` | Supporting | Possible for archive wardens and threshold denial, but should be handled as line tool, not bunker tool. |
| `Heavy Shield` | Excluded | Too static and mass-based for Naghii-origin Technique traditions. |

### How To Use This Appendix

To create a Naghii-origin Technique:

1. Pick one seed principle from the main list.
2. Pick one expression surface from this appendix.
3. Ask what problem that surface solves through that seed.
4. Write the Technique only after that combination creates a specific playable situation.

Examples:

- `Threshold Denial + Perforation` can produce a spear Technique like `Cerrar la Línea`.
- `Threshold Denial + Medium Shield` can produce an archive-warden interception Technique.
- `Absence As Evidence + Cryptology` can produce a Technique for avoiding a false translation under pressure.
- `Venom As Commitment + Dagger` can produce a poisoned-blade Technique that makes disengagement costly.
- `Projection Of Interpretation + Thrown Weapons` can produce a marking or warning Technique rather than a simple damage throw.

The appendix is not permission to write every possible combination. It is a pressure map for finding combinations that already sound like the Naghii before numbers are added.
