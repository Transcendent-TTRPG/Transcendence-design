# Knowledge Registries

This directory contains structured knowledge registries for the Transcendence design repository.

These files are not full rule sources. They are compact records that help:

- reduce repeated context reconstruction
- support simulator modeling
- track accepted doctrine
- expose source ownership
- summarize subsystem state

## Intended Registry Families

- `concept-registry.yaml`
- `decision-registry.yaml`
- `source-map.yaml`
- `project-state.yaml`

Additional registries can be added later for:

- simulator crosswalks
- species completion maps
- technique surface summaries
- state taxonomy maps
